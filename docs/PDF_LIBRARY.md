# 从 PDF 书库选页开始校对

在侧栏打开 **PDF 书库**，上传书籍，选取本次朗读需要的 PDF 物理页，保存材料并生成固定版本。回到“新建单任务”，参考材料选择“从书库选择”，即可直接使用，无须下载再上传。

## 准备一本书

1. 点击“上传 PDF”，可一次选择多本。上传只保存原件，不启动识别。
2. 打开书籍，填写书名、作者、版本和标签。列表按这些信息搜索并分页。
3. 用页导航检查原页；这里的第 1 页是 PDF 第一张页面，不是书上印刷的页码。
4. 根据需要识别本页、整本尚缺的页，或者先选页，再补齐材料缺页。确认框显示页数、模型和并发设置；只有确认后才调用现有 OCR 连接。

相同 PDF 会返回已有书籍，不重复建书；同名而内容不同的 PDF 分开保存。原 PDF 不原地替换。

桌面左右对照原页和文字；手机通过“原页／文字”切换。渲染失败只影响预览，不等于 OCR 失败。预览缓存上限为 256 MiB，可在书库清理缓存，不会删除 PDF、文字或材料。

## 修改页面文字

点击“保存修订”会新增修订，历史文字仍可展开查看。OCR 完成与人工修订分别显示，识别成功不表示已经人工审核。

**空白页也要有修订。** 尚无修订表示缺页；保存空白文字表示确认该页为空，不会把后面的页向前挪。

如果其他人先保存，系统提示冲突并显示最新版本，保留你的输入。比较后可以“以最新版本为基准继续编辑”，再保存；不会直接覆盖他人的当前修订。书目信息和材料草稿同样检查版本。

## 组合本次材料

在书籍详情输入起止物理页，点击“加入页段”。两端均包含。可以加入另一本书，也可以返回同一本书选另一个不连续页段。

进入“本次材料”后：

- 用拖动或上移／下移调整顺序；系统不自动按书名或页码排序。
- 重复页会提醒，但保留你的选择。材料总页数包含重复；补页识别只请求不同的缺页。
- 缺页时可以保存草稿；缺页补齐后才能生成固定版本。
- 点击“生成固定版本”，同时生成 PDF、TXT 和来源清单。任一产物失败，都不会显示为完成。

TXT 在换书或跳页处标明新来源片段，连续原页保留物理换页标记。来源清单逐页记录原书、版本、原页和文本修订。下载的材料版本固定不变；页面文字后来被修改时，只提示有更新，明确重新生成才得到新版。

## 用于网页单次校对

选择材料及固定版本后，页面显示书籍数、页数和文字准备状态。开始整理时，服务端先把 PDF、TXT 和来源清单固定到任务自己的附件目录，再接受任务。

任务只把 TXT 作为参考输入，不再次识别组合 PDF。附件可在任务详情查看或下载。之后归档、修改甚至清理书库材料，不影响已经接受的任务查看和参考阶段重跑。

原视频的恢复条件不变：如果成功任务已按原规则清理视频，要从抽取音频阶段重跑仍需重新提供视频；已有音频／ASR 的后续阶段不需要因此重跑 ASR。

普通上传、网页参考、CLI、批量和对谈方式保留原用法。书库选择仅接入网页单次读书会任务。

## 复用历史 OCR

点击“导入历史 OCR”，检查候选、可复用页数和来源警告，再勾选导入。也可从旧 PDF 书籍 OCR 页面进入。

- 原件和可靠页结果复制入库，不移动或修改旧任务。
- 部分成功任务可复用成功页，缺页继续保留未完成。
- 旧页缺少来源 sidecar，但父检查点身份可靠时可复用，标明来源信息不完整。
- 无法核实对应关系，或只有不能可靠分页的整本 TXT 时，只导入 PDF。
- 冲突来源需要明确选择；重复导入不重复建书，也不覆盖已有人工文字。

导入期间旧任务不能删除或重试。导入完成后删除旧任务，不影响书库原件和已接收文字。处理记录可以查看导入、材料生成和 OCR 的进度或错误。

## 归档、清理和中断

日常“归档”只隐藏列表记录，可在“查看归档”恢复。永久清理需要再次确认；书籍仍被任何保留材料版本或草稿引用时会拒绝。进行识别、导入、生成或任务快照复制时，冲突清理操作也会拒绝。

清理若失败会保留“清理未完成”记录，可重试永久清理；重启会继续完成已经批准的删除。正式资料没有自动过期清理。

重启后未结束的 OCR 显示可继续，不自动调用模型。点击继续时沿用原模型和执行参数、复用成功检查点；凭据仍从现有受控配置取得，不写入书库数据库。导入／材料生成中断后，从对应页面重新操作。

## 停服一致性备份与恢复

备份包含 `data/library/` 下的 SQLite、原 PDF、OCR 检查点和已发布材料。缓存和临时半成品不必备份。PDF 原件的总量不是备份总量，材料副本和历史也占空间。

以下是部署维护操作，**开发和测试不会替你执行**。从项目根目录，在确认可以停服后操作：

```bash
# 等待容器正常停止，不能一边写数据库一边只复制 sqlite3 主文件。
docker compose stop trans
backup="$HOME/transcript-library-backup-$(date +%Y%m%d-%H%M%S)"
mkdir -p "$backup"
tar --exclude='library/cache' --exclude='library/staging' \
    -cpf "$backup/library.tar" -C data library
docker compose start trans
```

恢复前保留当前资料作为回退点，使用可信备份：

```bash
docker compose stop trans
mv data/library "data/library.before-restore-$(date +%Y%m%d-%H%M%S)"
tar -xpf /你的备份目录/library.tar -C data
# 若迁移服务器，按现有容器 APP_UID/APP_GID 恢复目录读写权限。
docker compose start trans
```

恢复后检查健康接口，打开一本书预览一页，下载一个旧材料版本，并在单任务中选择它。不要用“重新识别整本”作为恢复检查。若需回退，再次停服后换回保留目录。

实施范围、验收证据与剩余事项见 [Epic 001](../codestable/epics/001-o-shared-pdf-library/spec.md)。
