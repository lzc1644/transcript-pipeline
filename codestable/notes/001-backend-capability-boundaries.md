# 后端四大能力的组合与状态边界

后端按“可独立执行的操作”拆分，读书会、文件转写、PDF 工具和听写复用同一套能力；产品层继续决定任务如何推进、状态归谁、结果何时发布。新增调用方直接传入文件、模型选项、资源位置和网关连接，不把完整项目配置、job 或 Web 当作能力的前提。

## 先选能力，再选产品流程

- **媒体处理**负责格式转换和限长 PCM 解码，供视频、音频文件及上传录音共用。
- **本地 ASR**包括文件／长音频、流式预览、最终短句识别。文件批处理复用模型或 worker；流式识别保留增量状态，短句识别保留无对齐器的既有算法与模型生命周期，不能用长音频批处理替代。
- **PDF 处理**负责单 PDF 逐页识别、检查点恢复、完整性检查，以及带物理页标记的 TXT 发布。参考提取与独立书籍工具复用核心，仍选用各自提示词和检查点根目录。
- **LLM 处理**分为通用网关和具体文字任务。网关只处理连接、HTTP/SSE 和文件传输；读书会／对谈校对、听写逐句／全文整理拥有各自提示词、输入装配和结果校验。PDF 专用提示词仍归 PDF。

读书会把媒体、ASR、参考准备、校对和导出组合起来；对谈可省略参考准备；文件转写只组合媒体和 ASR；PDF 工具只组合 PDF 与网关；听写使用流式／短句 ASR 和听写文字任务。

## 复用处理操作，不合并状态机

```text
Web / CLI → 产品编排 → 媒体 / ASR / PDF / LLM 任务
                                  PDF → 通用网关
                             LLM 任务 → 通用网关
```

产品编排负责配置快照、阶段顺序、工作区、批量并发和产物交付。听写服务继续拥有会话 owner、正文版本、人工编辑、暂停／结束、历史和共享识别排队；能力层不接管这些状态。精修消费 ASR 结果与已验证的配对，不依赖识别执行器；网关不反向依赖产品、PDF 或文字任务。

文件 ASR 与听写共享同一个 GPU 文件锁，并向 worker 继承锁 fd。文件识别阻塞等待锁，听写按原调度器非阻塞排队；听写暂停时保留资源。取消或结束仍须等真实 worker／HTTP 退出，不能只取消外层等待就宣称资源已释放。

## 接入或修改时必须保留的契约

- **连接隔离**：新能力和当前产品显式传递不可变连接快照，URL、认证、路由和代理跨后台线程、批量线程与页线程不串用。密钥不进入任务快照或日志。旧 `CodexLBClient(settings)` 保留每个完整请求起点读取配置的语义；旧环境上下文仍是进程全局兼容入口，不用于新产品并发。
- **外部兼容**：保留原 API、CLI 参数／退出码、启动入口、历史类型／异常导入、配置含义、主 JSON 和目录布局。`None` 继承，空字符串或 `False` 的既有显式关闭含义不变；不改模型 revision、默认组合和提示词正文。旧两步校对、CLI 模型后端、文字层／Tesseract、align／classify 和 TXT 合并入口继续保留。
- **ASR 与校对**：保留时间戳、结果发布和双 ASR 同源配对门禁；辅助识别失败或配对未完成不能进入联合校对。单 ASR 引用锁定、双 ASR 原始候选处理和多后端人工选择不混同。听写全文整理的分块共享同一总期限，不发布半篇建议。
- **PDF 完成**：空白页是合法成功页，物理页序及 `----- OCR_PAGE_BREAK: 1 -> 2 -----` 不变。身份仍由 PDF 内容、主模型、推理强度和原协议版本组成，不增加提示词等新身份字段；新成功页保留来源 sidecar。结果明确为 `success / partial / failed`，只有页面齐全且 TXT 发布成功才是 success；`resumable` 不是成功判据，缺少完成事件的 SSE 不能提交成功页。
- **PDF 恢复**：首轮不自动切模型；既有显式补页入口才会按父身份为符合条件的 GPT 输出失败页选择 Gemini。普通超时、TLS、限流或鉴权错误不新建切模计划。旧适配器继续保留异常和参考准备删除陈旧 TXT 的失败门禁，不回改历史产物。
