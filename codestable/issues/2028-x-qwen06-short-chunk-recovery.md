# Qwen 0.6B 短片段术语回显与日文对齐失败

用户要求先修 0.6B，再处理 1.7B 显存。关联历史接入：`005-o-asr-multi-backend-integration.md`。本轮仅 ASR 0.6B，不修改 1.7B 显存策略、默认模型，不部署或重跑全片。

## 证据与根因

容器日志的失败任务已被用户删除。按上传/任务日志定位同名后续 Whisper 任务的音频与术语配置，重新计算 VAD 得到相同失败边界；两类错误均真实复现，但不能证明已删除任务配置与当前样本配置逐项一致。

- 《简明世界史古代部分》第三章第一节，`[2633.456,2635.408]`：天然 1.952 秒 VAD 区间。长术语上下文导致模型逐项回显术语，生成 2048 token 未结束；非 OOM，也不是接入层制造的不足 1 秒尾块。同 PCM 无术语时正常结束。
- 哲学组会议，`[3.376,9.2]`：识别文字为日文问候。强制中文时 SDK 以中文规则把整串假名合成一个对齐单元，结果 `[4.8,4.8]`。同文字改用日文对齐得到 7 个有效单元。不带术语且允许语言检测时，SDK 自动识别 Japanese 并给出有效时间戳。
- 反证：仅为术语加“热词：”或说明性前缀仍回显；仅允许语言检测但保留长中文术语表，日文片段仍被预测为 Chinese。扩大 PCM 上下文虽能避免报错，却把日语输出成中文谐音，不作为修复。
- 首版统一中性重试（无术语 + 自动语言检测）在公共 CLI 上退出 0，但把历史讨论短中文夹英文识别成葡语 `Um box, por exemplo`。检查真实输出后否决，产物保留在 `rejected-auto-language-cli/`，**不是最终验收通过**。最终按两种原因分别处理，不再统一自动语言检测。

证据目录：`data/output/logs/qwen06-debug-20261004/`。隔离容器使用当前镜像、网络禁用、模型卷只读、项目 GPU 文件锁；原任务和上游音频未修改。

## 有界修复方案

不普遍去掉术语或改变语言配置。保留每块原有首试；仅 Qwen 0.6B 的两种**明确失败类型**允许一次局部恢复：

1. 无 EOS 的解码触顶且原来带术语：相同 PCM、精度、token 上限和模型 revision，不带术语上下文重试，但仍强制中文；没有术语时不做相同重试。
2. 全部零时长，且识别文字含假名、字母仅属日文假名/CJK 范围：保留原文字，只调用原 ForcedAligner 的 Japanese 分词规则重新对齐。不能将这种脚本判断当音频语言检测；纯中文、其他字母混合不启用。

最多一次恢复，不串联两种策略，没有跨模型/CPU 回退。其他异常（包括 OOM、空文本、词字不一致、越界时间戳）不重试。第二次失败即停止，保留两次原因，拒绝不完整产物。

每次恢复在日志及 metadata 中记录触发原因、音频区间、首试与重试语言/术语策略及处理阶段；输出明确告警，不能声称每块都使用了原术语。保留用户术语配置及正常块行为，不翻译日文、不猜测时间戳、不扩大/丢弃 PCM。

这修复的是适配层缺少对强上下文偏置失败的有界恢复，不声称修复模型权重本身或解决所有识别错误。无术语重试可能降低专名准确度，恢复块需人工复核；未来若大量块触发恢复或出现正常结束的术语幻觉，应另行评估术语输入策略，不增加无限重试。

## 验证目标

- 功能正确性：原失败 PCM 经实际 0.6B 推理得到非空、未截断、字词对应且有有效时间戳的结果；不以中文谐音或伪造边界替代。
- 可靠性与可追踪性：每块最多两次识别，只捕获明确类型；一次失败不污染后续块；二次失败不发布半成品；原始及实际参数可复核。
- 兼容与范围：JSON 主结构不变，metadata 仅追加；1.7B 和其他后端行为不变；既有短尾策略及 token 截断校验保留。
- 执行 `.venv/bin/python -m pytest`，测试首试成功/两类恢复/恢复失败/不应重试/日志与 metadata；真实公共 CLI 在独立输出目录跑失败片段和邻近上下文，核查文字与时间戳。

## 实现与真实复验

改动 `src/asr/qwen3_backend.py`、`src/asr/segmentation.py`、`tests/test_asr_backends.py`、`docs/ASR_BACKENDS.md`。使用专门的触顶/零时长异常类型，不按错误字符串模糊重试。恢复参数和状态只属于当前块/文件，下一块重新使用原术语；原截断与对齐校验不放宽。

最终隔离容器挂载本次两个后端文件，只运行 `/app/.venv/bin/python scripts/02_transcribe.py`，输出 `data/output/logs/qwen06-debug-20261004/cli/<case>/asr_dir/sample.{json,txt}`，每个目录保存配置、日志、退出码。六个样例退出码均为 0：

| 样例 | 片段时长 | 结果段数 | 恢复 |
|---|---:|---:|---|
| history-exact | 1.952s | 1 | 无术语、保留中文，1 次 |
| meeting-exact | 5.824s | 3 | 同一日文文本重新对齐，1 次 |
| history-context | 21.952s | 3 | 局部 `[10,11.952]` 无术语重试 |
| meeting-context | 19.2s | 6 | 局部 `[3.376,9.2]` 日文对齐 |

日文保留 `みなさんこんにちは。こんばんは。みなさんこんばんは。`，对齐得 7 个真实单元、3 个文本段。历史短片段输出 `Pox，我们说的。`，不再输出整份词表，也没有葡语误判；但 `Pox` 与既有 Whisper 的 `BOX` 不一致，附近文字也有识别差异，没有人工听校，**专名和短句仍需复核，不声称文字完全准确或整片可用已验收**。

首次生成精简 CLI 配置遗漏 5 个必填节，在本地配置校验阶段即失败，未执行模型；补齐非敏感配置并禁用 LLM 后执行真实验收。生产容器、默认模型、历史任务及原 ASR 产物均未更新；不得把隔离挂载文件测试说成已经部署。
